## 🛡️ About the Project

**Nanhey Accessories** is a high-conversion, professional CCTV & Security E-Commerce and doorstep installation platform designed for Begusarai and Bihar. It offers comprehensive surveillance hardware, biometric equipment, an interactive CCTV package builder with real-time pricing calculation, and direct technician booking.

---

## 🚀 Key Features

- **Top Announcement & Contact Bar**: Direct access to showroom location in Begusarai, hotline number, email, and social channels.
- **Main Search & Category Navigation**: Category-filtered search bar, account management, wishlist badge counter, and cart total preview.
- **Navigation Menu & Mega-Dropdown**: Quick links to CCTV Cameras, DVR/NVR, WiFi Cameras, Accessories, Offers, and Installation.
- **Security Hero Banner**: Sleek dark security theme with 4K UHD surveillance previews, USP chips, and quick consultation dials.
- **5-Pillar Value Proposition Strip**: Free delivery, 7-day returns, 100% secure payments, dedicated online support, and 1-tap WhatsApp ordering.
- **Category Grid**: 8 dedicated surveillance categories + View All catalog.
- **Interactive CCTV Package Builder**: Dynamic configurator allowing clients to select camera quantity (2/4/8/16), storage capacity (500GB/1TB/2TB), and audio recording, updating the price estimate in real time.
- **Best Selling Products Grid**: Top hardware from CP Plus, Hikvision, Seagate, and WD with instant "Add to Cart" capability.
- **Professional Installation Showcase**: Certified technician booking with 3-point quality checklist and quick lead capture modal.
- **Trust Badges Bar**: 10+ Years Experience, 5000+ Happy Clients, 100% Satisfaction, Bulk Discounts, GST Invoicing, and AMC Services.
- **Comprehensive Showroom Footer**: Company overview, Begusarai address, quick links, policies, and accepted payment methods.
- **Fixed Mobile Bottom Navigation**: High-conversion mobile bottom bar with Home, Catalog, Builder, Call, and WhatsApp triggers.

## 📦 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v22.13.1)
- npm 10+

### Installation & Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.
